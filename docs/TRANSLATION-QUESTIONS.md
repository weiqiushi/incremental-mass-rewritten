# 已确认的译名

以下译名已按“你的选择”应用到语言包。“原讨论点”和你的答复保留作为命名依据；后续调整只需修改语言包，不必修改游戏逻辑。

| 原文 | 已采用译法 | 原讨论点 | 你的选择 |
| --- | --- | --- | --- |
| Overpower | 超强化器 | 新增的第四种质量升级；是否沿用名称结构，改为“超强化器”等？ |超强化器 |
| Ascension / Transcension | 飞升 / 超越 | 原版有单独的飞升层级，与 NG+ 的进度不完全相同；这两个层级应否采用其他名称？ | 只要和当前版本的其他词语不冲突，就可以使用 飞升 / 超越 这个原意。不需要和NG+的进度一致 |
| Exotic Atoms | 奇异原子 | 原版的资源名称是 atoms，区别于 NG+ 的 Exotic Matter“奇异物质”。当前保留此区别。 | 奇异原子 |
| Muon-Catalyzed Fusion | 缪子催化聚变 | 采用物理术语译法，简称 MCF 保留原样；是否需要更短的界面名称？ | 缪子催化聚变 |
| Fabric | 时空纤维 | 新的重置资源，暂按时空结构含义翻译；也可用“时空纤维”或“织物”。 | 时空纤维比"织物"更像物理学术语，比较贴合游戏的氛围 |
| Protostar | 原初恒星 | 天文学也常用“原初恒星”；目前采用较短译法。 | 采用"原初恒星"，比"原恒星"歧义更少 |
| Protoversal Theorem | 原初宇宙定理 | 作者组合词，没有与旧版一一对应的名称；是否用“初始宇宙定理”等？ | 同上，我觉得"原初宇宙定理"比较好 |
| Escrow Boosts | 暂存加成 | 原文 escrow 有托管、暂存含义。当前按机制中的保留加成表达；是否改为“托管加成”？ | Escrow偏向于"托管，满足条件后交付"，这里使用"暂存加成"可能好些 |
| Corruption / Corrupted Star | 腐化 / 腐化星辰 | 与挑战 16 和无限后的资源统一用“腐化”；是否更偏好“腐蚀”？ | 腐化 / 腐化星辰 |
| Ouroboros / Ouroboric | 衔尾蛇 / 衔尾蛇重置 | 希腊神话名称采用通行译法；重置动作采用描述性译法。 | 衔尾蛇 / 衔尾蛇重置 |
| Calm Power | 宁静能量 | 与狂怒能量对照；是否更偏好“宁静能量”？ | 宁静能量 |
| Savage selected | 重铸选中定理 | 英文按钮疑似非标准用词。代码会消耗库存中的选中定理，并据此生成新的候选定理，故按操作意义翻译，未译成单纯“丢弃”。 | 重铸选中定理 |
| Purple / Violet Matter | 紫色 / 紫罗兰色物质 | 两种独立颜色的物质，需区分。当前对应深紫与紫色；是否使用“紫色 / 紫罗兰色”？ | 紫色 / 紫罗兰色 比较好 |
| Pent / Tetr | 五重阶层 / 四重阶层 | 沿用旧汉化版名称。原版 Tetr 的字根对应四，旧版名称与字根不完全一致；是否在此版统一改为“四重阶层”？ | 这里看上去是旧汉化版的错误，之前我就疑惑为什么没有四重阶层。这里改正确即可 |
| >118 的系统元素名称 | 名称与符号保留英文；说明引用用元素编号 | 虚构元素系统命名没有对应的正式中文名。当前保留索引和符号，避免逐个创造音译。 | 可以 |

其余质量、狂怒能量、暗物质、夸克、时间速度、黑洞压缩器、量子泡沫、黑暗狂奔及常见折算名称，优先沿用旧汉化版。
